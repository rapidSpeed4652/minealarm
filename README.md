# MineAlarm
A sophisticated (atleast according to me) alarm clock with four buttons and a buzzers. The case is based on Minecraft.

[![View PCB on KiCanvas](https://hack.club/pcb-badge)](https://kicanvas.org/?repo=https://github.com/rapidSpeed4652/minealarm/tree/main/pcb)

# Mechanism ⚙️
## 1) Normal mode ☑️
Mostly in this mode, where most of the buttons don't do anything.

Long pressing button 3 arms/disarms the alarm.

## 2) Setting time mode 🕝
To enter into this mode, the button 1 should be long-pressed (>800ms).

In this mode, button 2 acts as '+', button 3 as '-' and button 4 as am/pm switcher.
Pressing button 1 in this mode changes whether you are changing the hours or minutes.

To exit the mode, long press button 3.

## 3) Setting alarm mode ⏰
To enter into this mode, the button 4 should be long-pressed (>800ms)

In this mode, button 1 acts as '+', button 2 as '-' and button 3 as am/pm switcher.
Pressing button 4 in this mode changes whether you are changing the hours or minutes.

To exit the mode, long press button 3.

## 4) Alarm Ringing mode 🔊
The mode cannot be entered by the user, it is automatically entered when the alarm time matches with the current time.

Button 2 acts as snooze button and Button 3 as dismiss button.
